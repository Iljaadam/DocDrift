Coverage & limitations

Acceptance covers only declared inputs and recorded checks. It is not a proof for every input or protection against deliberately obfuscated code. The static must-flow check trusts straight-line top-level code and can reject legitimate complex rewrites.

Current behavior checks compare frozen JSON outputs, require the declared API call, and check that its result reaches printed output. Inspect each operation’s recorded coverage when reviewing historical runs; a known-repair AST match is informational.

Saved coverage note

Only the frozen JSON outputs across declared inputs, the required API call, and that call result reaching the printed output (static must-flow check) are checked. This owned-fixture result alone does not establish competition eligibility.
